# 博客核心功能

当前按个人博客使用：管理员负责文章管理，访客无需登录即可阅读已发布文章。公开注册的账号默认是普通用户，不能进入后台。所有管理员均可管理博客文章。

## 升级已有环境

停止旧应用后，对独立 `myblog` 库按顺序执行：

1. `db/migration/V3__account_security.sql`：扩展密码字段，新增用户角色。
2. `db/migration/V4__article_lifecycle.sql`：新增文章状态、首次发布时间和发布索引。

两个脚本均只执行一次，不要重复执行。新环境先执行 V1、V2，再执行 V3、V4。应用不会自动执行迁移。V4 将已有文章保留为已发布，并补充发布时间；今后新文章默认是草稿。

2026-11-06 已对仓库默认 NAS `myblog` 库执行 V3、V4。

使用 JDK 21 运行 `mvn clean install` 后，按 README 的顺序启动六个 WAR。跨应用配置新增 `manager.public-base-url`，本地默认为 `http://localhost:8084`。登录回跳只允许配置的门户和后台地址及其上下文路径。

## 创建管理员

1. 打开 SSO 的 `/page/register`，注册自己的账号；密码长度为 8–128 个字符，手机号和邮箱可以留空。
2. 在数据库确认账号身份，再明确提升该账号：

```sql
SELECT id, username, role FROM tb_user WHERE username = '你的用户名';
UPDATE tb_user SET role = 'ADMIN', updated = NOW()
WHERE username = '你的用户名' AND role = 'USER';
```

3. 访问后台 `http://localhost:8084/`，完成登录后会返回后台。门户登录后也会显示账号和后台入口。

应用没有默认管理员或默认密码，公开注册不能授予管理员权限。撤销权限可将指定账号的 `role` 更新为 `USER`；下一次后台请求立即重新校验数据库角色。

## 写作与发布

- **保存草稿**：保存后可继续编辑，前台列表和详情均不可访问。
- **预览**：在后台沙箱预览当前编辑内容，不需要先公开文章。
- **发布文章**：保存并公开，首次发布设置 `publishedAt`；修改或重新发布保留首次发布时间。
- **下架**：从管理列表下架，前台详情返回 404；可再次编辑、发布。
- **删除**：支持单篇和批量删除；不存在的文章明确返回错误。

保存成功后网页使用返回的文章 ID 继续编辑。业务校验失败或请求失败都会保留当前编辑内容；离开未保存内容时提示确认。上传图片限制为 5 MiB。

标题长度为 1–50 个字符，标签最多 50 个字符，正文最多 65535 UTF-8 字节。正文在保存时通过 HTML 白名单清洗，保留常用格式、图片和链接；空正文会被拒绝。历史正文在前台读取时同样清洗。前台摘要按纯文本输出。

门户只查询已发布内容，并使用独立的已发布文章缓存命名空间。增删改和状态变更继续触发 Kafka 缓存失效。不公开的文章与不存在的文章均返回友好 404；非法分页参数返回 400，每页最多 100 篇。

## 内容检索

门户首页提供标题关键词和标签筛选，使用原生 GET 表单，链接可以收藏或分享。例如 `/?q=Java&tag=后端&pageNum=1&pageSize=10&orderBy=new`。

- 关键词匹配文章标题中包含的文字；`%`、`_`、`=` 等字符按字面搜索。正文不参与此次检索。
- 标签使用已有的单个字符串字段，按整个标签精确筛选，不拆分逗号或空格。列表和详情中的标签均可点击进入筛选。新写入的标签会去除首尾空白。
- 关键词与标签可以组合，同时满足两个条件才展示。输入会去除首尾空白，各最多 50 个 Unicode 字符，超长返回友好 400。
- 仅检索已发布文章；标签下拉框也只来自已发布文章，排除空标签并去重。
- 页面展示匹配总数、当前条件、无结果提示与清除入口。分页保留关键词、标签和每页条数，切换最新 / 最热或重新搜索时回到第一页。

搜索页按关键词、标签、排序、页码和每页条数隔离 Redis 缓存，标签选项与搜索结果共用文章缓存版本。文章发布、改名、修改标签、下架或删除后，通过现有 Kafka 链路使两者失效。Redis 故障时回源 MySQL。

本轮不需要新增数据库迁移或外部搜索服务。门户接口新增五参数查询重载并保留原三参数方法，分页结果新增 `total`；部署时应重新构建共享模块并同时更新 portal-service 与 portal-web。

## 身份与请求保护

后台页面、文章接口和图片上传统一校验 SSO 会话及 `ADMIN` 角色；图片读取和静态资源仍可公开访问。新增文章的作者由当前登录账号确定，客户端不能更改作者、统计和时间字段。

所有写操作使用 POST 并校验 CSRF。退出会删除 Redis 会话和认证 Cookie，旧 token 无法继续操作。SSO 使用独立的表单会话 Cookie，认证 Cookie 使用 HttpOnly、SameSite=Lax，在 HTTPS 请求下启用 Secure。开发环境不同端口共用同一个主机名；生产环境应通过同主机反向代理访问三个 Web 应用，避免 host-only Cookie 无法在不同主机间共享。

新密码使用随机盐 PBKDF2 SHA256；已有 MD5 密码在成功登录时自动升级。应用不记录密码。登录与注册失败均保留明确的页面反馈。
